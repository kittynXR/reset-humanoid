# cátte — Reset Humanoid

Simple tool to reset the pose of a humanoid animator.

## Features

- Reset humanoid bone transformations to their default pose
- Options to reset position, rotation, and/or scale individually
- Full reset mode to include all imported objects
- Undo support

## Installation

Install via VRChat Creator Companion (VCC) or add to your Unity project's Packages folder.

## Usage

1. Open the tool via `Tools > ⚙️🎨 kittyn.cat 🐟 > Reset Humanoid > Reset Humanoid`
2. Select the Animator component you want to reset
3. Choose which transformations to reset (Position, Rotation, Scale)
4. Optionally enable "Full Reset" to include all imported model objects
5. Click "Reset" to apply

## Requirements

- Unity 2019.4 or later
- Humanoid avatar with an Avatar asset
